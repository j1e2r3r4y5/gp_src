一、项目概述

本项目是一个前后端分离的 4G 物联网设备管理平台，用于管理和监控 4G DTU（数据传输单元） 设备。

1.1 什么是 4G DTU？

DTU (Data Transfer Unit) 是数据传输单元，是一种用于将串口数据通过 4G 无线网络进行传输的工业设备。

特点说明
远程通信通过 4G 网络实现无线连接
Modbus 协议支持连接多种工业传感器和设备
数据透传将下位机数据上传至云端服务器
远程控制支持远程配置和控制，无需现场操作

六、通信协议详解

6.1 上报协议（设备 → 服务器）

功能码名称数据格式处理逻辑
00心跳包1 字节功能码更新设备在线状态
01上发模组配置功能码 + 发送模式 + 配置数据 + 波特率更新设备通信参数
02模组配置结果功能码 + 成功状态 (0-5)记录配置下发结果
03数据配置上发功能码 + 数量 + 各配置项记录变量配置信息
04数据配置结果功能码 + 成功状态同步缓存表和变量表
05数据上发功能码 + 数量 + 各数据项解析数据并写入 InfluxDB

6.2 下发协议（服务器 → 设备）

功能码名称数据格式用途
01模组配置查询1 字节功能码查询设备当前配置
02下发模组配置功能码 + 发送模式 + 配置数据 + 波特率配置设备通信参数
03数据配置查询1 字节功能码查询设备变量配置
04下发数据配置功能码 + 数量 + 变量配置配置设备上报变量
06远程置数功能码 + 类型 + 地址 + 数量 + 数值远程控制设备输出

十四、常见问题与解决方案

14.1 设备无法上线

可能原因排查步骤解决方案
网络问题检查 4G 信号确认 SIM 卡正常
MQTT 未连接检查 Broker 地址确认端口 10213 可达
序列号错误核对设备序列号在平台注册正确序列号
防火墙拦截检查防火墙规则开放相应端口

14.2 配置下发失败

可能原因排查步骤解决方案
设备离线检查设备状态确保设备在线
波特率不匹配核对波特率设置两端设置一致
功能码错误检查协议格式确认数据格式正确

14.3 登录失败

错误码说明解决方案
53账号或密码错误检查用户名密码
54账号已禁用联系管理员
66Token 无效重新登录
