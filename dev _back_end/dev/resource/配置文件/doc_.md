下发01 模组配置查询\
1字节功能码

上发01 上发模组配置\
1字节功能码 1字节发送模式（00定时发送  01线圈置1触发发送 02线圈器变化触发发送）
2字节配置数据（00模式为发送间隔，其他模式为触发地址） 1字节波特率\
\
\
\
下发02 下发模组配置 共计4字节\
1字节功能码 1字节发送模式（00定时发送  01线圈置1触发发送 02线圈器变化触发发送） 
2字节配置数据（00模式为发送间隔，其他模式为触发地址） 1字节波特率
波特率配置：

| 值   | 波特率 |
| ---- | ------ |
| 0x00 | 300    |
| 0x01 | 600    |
| 0x02 | 1200   |
| 0x03 | 2400   |
| 0x04 | 4800   |
| 0x05 | 9600   |
| 0x06 | 14400  |
| 0x07 | 19200  |
| 0x08 | 28800  |
| 0x09 | 38400  |
| 0x0A | 57600  |
| 0x0B | 76800  |
| 0x0C | 115200 |
| 0x0D | 230400 |
| 0x0E | 460800 |
| 0x0F | 921600 |



上发02 模组配置结果\
1字节功能码 1字节成功状态（0：成功，1：打开存储错误，2：写入存储失败，3：触发模式错误，4：数据接收长度错误，5：波特率配置错误）\
